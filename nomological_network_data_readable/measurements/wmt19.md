# WMT19
**Type:** Measurement  
**Referenced in:** 4 papers  
**Also known as:** WMT-19  

## State of the Field

**What it is.** Across the papers, the prevailing treatment of WMT19 is as a machine translation benchmark from the Workshop on Machine Translation 2019 or the WMT19 shared task. The descriptions vary slightly in form: some call it a benchmark used to evaluate machine translation systems, while one paper calls WMT-19 a dataset and uses the Kazakh-English subset; the cited content ranges from language pairs such as De-En, Fi-En, Lt-En, and Ru-En to that Kazakh-English subset.

**What it is claimed to measure.** In the recorded relationships, papers use WMT19 to measure Machine translation. The claims converge on that single behavioral indicator: it is linked to 1 behavioral indicator, Machine translation, and no constructs.

**Space of uses.** Papers often use WMT19 alongside other machine translation benchmarks. In the excerpts it appears alongside WMT14, and some papers also list IWSLT14, afroMT, IWSLT17, and WMT18 in the same evaluation setup; a smaller use treats it as the Kazakh-English subset for evaluating fine-tuning after coreset selection, and one description also presents it for evaluating translation performance and uncertainty.
