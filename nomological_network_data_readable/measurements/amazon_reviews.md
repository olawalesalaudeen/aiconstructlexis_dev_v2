## State of the Field

**What it is.** Across the papers, the prevailing description is a widely used public dataset of Amazon product reviews. One description presents it as reviews across multiple categories, used for sentiment analysis and for evaluating model performance on commercial user feedback, while another describes an adapted version that adds simulated user consultation texts, user profiles, and interaction behaviors for evaluation.

**What it is claimed to measure.** Papers use it to evaluate sentiment analysis performance on commercial user feedback, and one adapted use supports evaluation with consultation texts, user profiles, and interaction behaviors in work on users’ search motivations. Papers do not explicitly link it to any construct or behavioral indicator.

**Space of uses.** The reported uses are task-specific rather than presented alongside other named instruments. In one line of work it serves as a product review dataset for sentiment analysis, and in another it is adapted with simulated consultation text and interaction data for evaluation; no other measurement instrument is linked to it.
