# SYNC
**Type:** Measurement  
**Referenced in:** 1 paper  

## State of the Field

SYNC (SYNthetic Contexts) is a synthetic long-context evaluation suite with graph understanding and unseen-language translation tasks designed for controlled comparisons of LLM capabilities.
