# LASER
**Type:** Measurement  
**Referenced in:** 1 paper  

## State of the Field

An LLM-based ASR evaluation rubric that uses detailed prompts with error type examples to assign no, minor, or major penalties based on semantic impact, producing a sentence-level score.
