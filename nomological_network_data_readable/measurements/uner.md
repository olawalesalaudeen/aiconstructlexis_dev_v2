# UNER
**Type:** Measurement  
**Referenced in:** 3 papers  

## State of the Field

**What it is.** In one paper, UNER is described as a multilingual named entity recognition dataset covering 13 languages. The same description presents it as an evaluation resource for cross-lingual transfer on NER tasks, and the usage note in Translation and Fusion Improves Cross-lingual Information Extraction places it among multilingual NER datasets gathered for that purpose.

**What it is claimed to measure.** Papers describe UNER as used for evaluating cross-lingual transfer performance on named entity recognition tasks. No construct links and no behavioral-indicator links are recorded for it, so the available evidence stays at the task-level description rather than tying it to a broader construct.

**Space of uses.** The available usage description places UNER alongside MasakhaNER2.0, with papers treating both as multilingual NER datasets gathered for evaluation. Beyond that pairing, no other instrument links are recorded.
