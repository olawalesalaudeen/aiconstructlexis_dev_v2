# Wikidata
**Type:** Measurement  
**Referenced in:** 6 papers  
**Also known as:** WikiData  

## State of the Field

**What it is.** Across the available definitions, papers treat Wikidata as a schema matching dataset for a general knowledge base, used to test whether schema matching approaches generalize on structured open-domain data. One paper explicitly places it in a cross-domain evaluation setting, stating that authors evaluate on "Magellan (e-commerce) and WikiData (general knowledge base)" to assess generalizability to other domains (Bootstrapping Self-Improvement of Language Model Programs for Zero-Shot Schema Matching).

**What it is claimed to measure.** In the reported relationships, papers use Wikidata to measure one behavioral indicator, Schema matching, and it is not linked to any constructs. The linked usage converges on that single indicator rather than spreading across multiple targets: papers report schema matching as measured by Wikidata.

**Space of uses.** Papers use Wikidata as an evaluation benchmark for schema matching, and one explicit usage description positions it as further evaluation for generalizability to other domains rather than as a standalone setting. In that description, it appears alongside Magellan.
