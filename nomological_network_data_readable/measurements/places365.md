# Places365
**Type:** Measurement  
**Referenced in:** 3 papers  

## State of the Field

**What it is.** Across the papers, Places365 is most commonly described as a large-scale scene-centric image dataset with 365 scene categories, used for scene recognition or classification tasks. A smaller framing presents it as a scene classification benchmark used to evaluate descriptions on scene categories, so papers alternate between calling it a dataset and a benchmark while keeping the same scene-category focus.

**What it is claimed to measure.** Across the papers, Places365 is used to measure Image classification, and this is its only linked behavioral indicator. It is not linked to any constructs, so the reported measurement use centers on 1 behavioral indicator rather than multiple constructs or indicators.

**Space of uses.** No measurement instrument is linked to it. Papers position Places365 as part of broader multi-dataset evaluations, for example alongside CIFAR-10, CIFAR-100, and CUB, and another paper includes it among 12 image recognition datasets; one study also notes that "BLIP2 FlanT5 performs better on the Places365 dataset," explicitly treating it as a scene classification dataset.
