# Embedding cosine similarity
**Type:** Measurement  
**Referenced in:** 2 papers  
**Also known as:** Cosine similarity in embedding space  

## State of the Field

An embedding-based comparison procedure used to quantify semantic drift between an original input and its counterfactual explanation.
