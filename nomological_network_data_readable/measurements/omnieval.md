# OmniEval
**Type:** Measurement  
**Referenced in:** 1 paper  

## State of the Field

An omnidirectional RAG benchmark in the financial domain that evaluates systems across 16 topics and 5 tasks using both rule-based and LLM-based metrics on auto-generated and human-annotated datasets.
