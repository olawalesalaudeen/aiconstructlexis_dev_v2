# AgentBoard
**Type:** Measurement  
**Referenced in:** 3 papers  
**Also known as:** AGENTBOARD  

## State of the Field

**What it is.** Across papers, the prevailing framing is of AgentBoard as a standardized or comprehensive benchmark for evaluating LLM agents. Definitions describe it as a unified, open-source evaluation framework for multi-turn agents, with diverse tasks in partially-observable environments and analytical metrics beyond success rates; other papers describe it more broadly as a collection of diverse tasks, or as a benchmark spanning various environments to assess agent performance in tasks such as reasoning and planning.

**What it is claimed to measure.** Measurement claims converge on a single construct: papers use AgentBoard to measure Agency. The linked evidence describes it as a collection of diverse tasks for evaluating language models' agentic capabilities, and another paper places it under real-world applications; no behavioral indicators are linked to it.

**Space of uses.** Papers position AgentBoard as a benchmark and evaluation framework for agent evaluation, including analytical evaluation of LLM agents. In use, it appears alongside AgentBench in standardized agent evaluation setups, and some descriptions also group it with ToolBench in broader benchmark suites for assessing agent performance; no other measurement instrument is linked to it.
