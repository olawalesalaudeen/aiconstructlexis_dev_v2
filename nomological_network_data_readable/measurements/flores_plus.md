# FLORES+
**Type:** Measurement  
**Referenced in:** 6 papers  

## State of the Field

**What it is.** In the available definitions, FLORES+ is treated as a multilingual parallel-sentence dataset. The only described use frames it as an out-of-domain dataset for visualizing cross-lingual alignment with t-SNE, and one paper says it "randomly sample[s] 100 parallel sentences" for that examination (Debiasing Multilingual LLMs in Cross-lingual Latent Space).

**What it is claimed to measure.** Papers in the available evidence do not link FLORES+ to any construct or behavioral indicator through explicit measurement claims. The only stated evaluation target is cross-lingual alignment in a visualization setting, where authors examine sentence representations with t-SNE rather than report it as measuring a broader construct.

**Space of uses.** The documented usage is narrow: papers use FLORES+ as an out-of-domain set for visualization. In the reported procedure, authors sample 100 parallel sentences and inspect their cross-lingual alignment with t-SNE; no linked instruments are reported alongside it.
