# Value Kaleidoscope
**Type:** Measurement  
**Referenced in:** 4 papers  
**Also known as:** ValuePrism  

## State of the Field

**What it is.** Papers most commonly treat this entity as an evaluation dataset for moral scenarios and judgments. One definition describes Value Kaleidoscope as a benchmark with 31K human-authored hypothetical scenarios and moral dilemmas paired with ethical perspectives, used to test whether models support, oppose, or remain neutral toward scenarios from specific viewpoints. A second description uses the name ValuePrism (VP) and frames it more briefly as a moral-judgment dataset with three-way choices for evaluating value profile modeling of ethical reasoning.

**What it is claimed to measure.** Claims about what it measures converge on one construct: Value orientation. Papers link it to one construct, Value orientation, and do not link it to any behavioral indicators; in the linked use, it is used to probe models' views on moral situations, alongside Anthropic's Election Questions for political topics. Papers do not link it to any other measurement instruments.

**Space of uses.** Papers use it as an evaluation benchmark. One study places Value Kaleidoscope within "trade-off steerability benchmarks" for assessing proposed approaches, while another uses VP as a moral-judgment dataset in value profile modeling and says that for "HK and VP, clustering preserves a significant amount of information (≥20%) but is not as predictive." It also appears alongside Anthropic's Election Questions when papers probe models' views on political topics and moral situations.
