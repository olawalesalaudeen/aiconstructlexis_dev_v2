# PLLuM-Align
**Type:** Measurement  
**Referenced in:** 1 paper  
**Also known as:** PLLuM Preference Dataset  

## State of the Field

Polish preference dataset containing human-annotated response ratings, rankings, and multi-turn dialogues for evaluating alignment in Polish LLMs.

## Sources

**[PLLuM-Align: Polish Preference Dataset for Large Language Model Alignment](https://aclanthology.org/2025.emnlp-main.1219.pdf)**
