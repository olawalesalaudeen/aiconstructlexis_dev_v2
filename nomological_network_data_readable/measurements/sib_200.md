# SIB-200
**Type:** Measurement  
**Referenced in:** 6 papers  

## State of the Field

**What it is.** Across the papers, the prevailing description is a multilingual text classification benchmark spanning 204 languages and multiple domains, used to evaluate cross-domain generalization and classification accuracy. Some papers describe it more narrowly as a seven-way topic classification dataset, and one paper describes it as representing 200 languages. Papers also note that it supports both high and low-resource languages.

**What it is claimed to measure.** Papers use SIB-200 to measure one behavioral indicator, Text classification, and no constructs are linked to it. The reported use converges on text classification rather than spreading across multiple outcomes, with several papers describing the task more specifically as topic classification, including a seven-label setup.

**Space of uses.** Papers position SIB-200 both as a widely adopted multilingual benchmark in zero-shot evaluation and as a main grounding dataset for research. One reported use chooses it for topic classification because it has seven labels and supports a variety of high and low-resource languages, while another reports instruction tuning on each domain and evaluation across all other domains within SIB-200. Papers do not link it to any other measurement instrument.
