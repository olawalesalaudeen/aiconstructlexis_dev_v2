# HH-RLHF helpful subset
**Type:** Measurement  
**Referenced in:** 2 papers  
**Also known as:** HH-RLHF-helpful, Anthropic Helpfulness dataset  

## State of the Field

A binary human-preference dataset of helpfulness-oriented response comparisons used to test reward-model explanations.
