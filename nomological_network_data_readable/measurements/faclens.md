# FacLens
**Type:** Measurement  
**Referenced in:** 1 paper  

## State of the Field

A lightweight, transferable probe model that uses hidden representations of fact-seeking questions to predict the likelihood of non-factual responses before generation, applicable across multiple LLMs via domain adaptation.
