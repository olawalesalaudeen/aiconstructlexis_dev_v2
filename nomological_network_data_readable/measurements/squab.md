# SQUAB
**Type:** Measurement  
**Referenced in:** 1 paper  

## State of the Field

An automatic dataset generator for ambiguous and unanswerable questions in semantic parsing, producing annotated tests across six categories: Column Ambiguity, Scope, Attachment, Column Unanswerable, Calculation Unanswerable, and Out-of-Scope.
