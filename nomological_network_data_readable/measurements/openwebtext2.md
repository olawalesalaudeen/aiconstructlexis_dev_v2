# OpenWebText2
**Type:** Measurement  
**Referenced in:** 3 papers  

## State of the Field

**What it is.** Across the available definitions, OpenWebText2 is most commonly described as a large-scale web-text corpus or dataset. Papers characterize it as text extracted from URLs shared on Reddit and used to evaluate language model performance via perplexity, while another description treats it more generally as an evaluation corpus for computing Diff-eRank and reduced loss.

**What it is claimed to measure.** Papers do not explicitly link OpenWebText2 to any construct or behavioral indicator. Rather than presenting it as a measure of a named construct, they describe it operationally as a corpus used for evaluation through perplexity, Diff-eRank, and reduced loss.

**Space of uses.** The reported usage is mainly evaluative. One paper compares model performance on OpenWebText2, and another considers including it when computing Diff-eRank and also lists it alongside Wikipedia and other pre-training datasets for OPT models.
