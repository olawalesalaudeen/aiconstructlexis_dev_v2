# GeoQA
**Type:** Measurement  
**Referenced in:** 5 papers  

## State of the Field

**What it is.** Across the surveyed work, GeoQA is most commonly described as a geometry question-answering or geometry problem benchmark for evaluating multimodal geometric problem solving. Definitions vary slightly in what they foreground: one emphasizes questions and images, while another emphasizes diagrams, textual descriptions, and the need for complex reasoning.

**What it is claimed to measure.** Across the papers, GeoQA is linked to one construct, Geometric reasoning, and to no behavioral indicators. In G-LLaVA: Solving Geometric Problem with Multi-Modal Large Language Model and Theorem-Validated Reverse Chain-of-Thought Problem Generation for Geometric Reasoning, it is used to measure Geometric reasoning, so the measurement claims converge on a single construct rather than spreading across many.

**Space of uses.** In the cited evaluations, papers use the test set of GeoQA alongside the geometry problem solving task, testmini split, of MathVista. One paper also compares model performance on GeoQA with traditional methods in the geometry problem solving domain, which positions it as an evaluation benchmark for model comparison.
