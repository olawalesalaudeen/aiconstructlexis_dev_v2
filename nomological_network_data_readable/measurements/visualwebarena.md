# VisualWebArena
**Type:** Measurement  
**Referenced in:** 7 papers  
**Also known as:** V-WebArena  

## State of the Field

**What it is.** Across the cited definitions, the prevailing usage treats VisualWebArena, also written VWA or V-WebArena, as a benchmark environment for evaluating multimodal web agents on realistic visual web tasks. Most descriptions emphasize tasks across classifieds, social media, and shopping platforms, and papers also call it "a real environment for web agents". One reported use focuses on a subset of 72 easy tasks.

**What it is claimed to measure.** Papers link it to 2 constructs and 1 behavioral indicator. The reported measurement claims are that it measures Planning and Reasoning, and that it measures the behavioral indicator Web navigation; one paper describes it as a benchmark designed to evaluate multimodal agents across a wide range of web navigation tasks and environments. These measurement claims do not converge on a single construct.

**Space of uses.** No measurement instrument is linked to it in papers. Papers position it as a base environment for added evaluations: one study manually creates 200 targeted adversarial tasks and evaluation scripts on top of VisualWebArena in a realistic threat model, another uses a subset of 72 easy tasks and mentions integrating pop-ups into environments like OSWorld and VisualWebArena. It is also referenced for comparison under the name V-WebArena.

**Concerns raised.** Some reported uses focus on targeted adversarial tasks and pop-ups added to the environment, including evaluation scripts built in a realistic threat model.
