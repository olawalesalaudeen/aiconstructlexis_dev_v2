# WMT23
**Type:** Measurement  
**Referenced in:** 5 papers  
**Also known as:** WMT’23, WMT 2023  

## State of the Field

**What it is.** Across definitions, WMT23 is most commonly described as a 2023 Workshop or Conference on Machine Translation shared-task dataset or benchmark for evaluating translation quality across multiple language pairs and systems. Some descriptions add that it contains human-rated translations, and one paper specifically refers to WMT'23 MQM ratings for English-German and Chinese-English, while another presents it more simply as the 2023 test set for machine translation quality evaluation.

**What it is claimed to measure.** Papers link it to 1 behavioral indicator and no constructs. The only recorded measurement claim is Machine translation: one paper treats Machine translation as measured by WMT23, and the definitions consistently describe the benchmark as evaluating translation quality across multiple language pairs.

**Space of uses.** No other measurement instrument is linked to it. Papers use WMT23 as an evaluation test set or benchmark, including for fine-grained machine translation evaluation and as a generative task benchmark; one paper uses WMT'23 MQM ratings for English-German and Chinese-English, while another uses WMT 2023 as the source of contaminated test examples.

**Concerns raised.** Contamination is the only explicit concern papers raise. One study describes WMT 2023 as the source of contaminated test examples covering 10 language pairs, and reports that 681 examples from WMT'23 were removed during decontamination, leaving 9,491 examples.
