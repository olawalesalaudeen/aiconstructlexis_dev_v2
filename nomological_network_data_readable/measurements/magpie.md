# MAGPIE
**Type:** Measurement  
**Referenced in:** 3 papers  

## State of the Field

**What it is.** In the surveyed work, MAGPIE is described as a corpus of potentially idiomatic expressions labeled as figurative or literal. The definition also presents it as a resource used to test whether global affinity distinguishes figurative from literal usage.

**What it is claimed to measure.** Papers link MAGPIE to one behavioral indicator, Idiom identification, and to no constructs. The recorded use is as a measure of idiom identification, with one study stating that it adapts the dataset for the identification task.

**Space of uses.** The reported use treats MAGPIE as a task dataset, with one study noting that it adapts the dataset for the task and applies some filtering. No other measurement instrument is linked to it.
