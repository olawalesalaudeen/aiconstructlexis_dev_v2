# UltraChat
**Type:** Measurement  
**Referenced in:** 16 papers  

## State of the Field

**What it is.** Across the surveyed work, the prevailing description is of a diverse, multi-turn conversational instruction-following dataset, created using GPT-3.5-Turbo. Some papers frame it more specifically as a dialogue benchmark for interactive dialogue, while others use it as a held-out, out-of-domain dataset for testing whether a method generalizes beyond summarization. Definitions also mention its use for supervised fine-tuning and for generating prompts for self-training.

**What it is claimed to measure.** Papers use UltraChat to measure 2 constructs and 3 behavioral indicators. The linked behavioral indicators are instruction following, question answering, and text generation, and the linked constructs are instruction following ability and utility preservation. The recorded claims are distributed across several targets: papers variously describe it as an instruction task, a large-scale dataset of instructional conversations, a source of testing problems, or a benign utility-oriented dataset.

**Space of uses.** Papers position UltraChat in several roles rather than only as a standalone benchmark. Some use random samples from it for supervised fine-tuning or for self-training prompts, some use it as a benign source for quantization-assisting data and safety-patching evaluation, and others use it as an interactive dialogue task or as a held-out, out-of-domain evaluation setting. No other measurement instrument is linked to it.
