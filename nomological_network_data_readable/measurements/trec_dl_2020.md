# TREC-DL 2020
**Type:** Measurement  
**Referenced in:** 5 papers  
**Also known as:** TREC-DL20, TREC-DL'20, TREC-DL2020, TREC DL 2020  

## State of the Field

**What it is.** Across these papers, TREC-DL 2020 is most commonly described as a benchmark dataset or test set from the TREC Deep Learning Track 2020, used to evaluate passage retrieval, reranking, document relevance, and document re-ranking systems. The descriptions vary slightly: some present it as an in-domain dataset, one says it is derived from MS-MARCO-V1, and another describes it as extending TREC DL 2019 with additional queries and relevance annotations. One source also treats it simply as part of the "TREC-DL2019/2020 benchmarks."

**What it is claimed to measure.** Papers use TREC-DL 2020 to evaluate performance on passage retrieval and reranking style tasks, including document relevance assessment in LLM-based ranking settings. At the same time, papers do not explicitly link it to any construct or behavioral indicator, so its recorded use here is task evaluation rather than measurement of named constructs.

**Space of uses.** The prevailing usage is as a benchmark in evaluation suites for retrieval and re-ranking systems. Papers frequently use it alongside TREC-DL19, while some descriptions also place it with BEIR or in conjunction with MS MARCO; one paper notes that TREC-DL'19 and TREC-DL'20 are "not reasoning intensive."
