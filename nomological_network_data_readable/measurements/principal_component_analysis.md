# Principal component analysis
**Type:** Measurement  
**Referenced in:** 8 papers  
**Also known as:** PCA, PCA Visualization, Principal Component Analysis  

## State of the Field

Across the provided literature, Principal Component Analysis (PCA) is consistently described as a dimensionality-reduction technique, though its specific applications vary. One use is to analyze a model's internal states by applying PCA to "residual stream activations" to visualize the "geometric structure of numerical representations across model layers" (Probing for Arithmetic Errors in Language Models). Another application treats PCA as a "lens function" for projecting embeddings into a low-dimensional space, a process which "emphasizes directions of high variance" and highlights "global variance" (When Annotators Disagree, Topology Explains: Mapper, a Topological Tool for Exploring Text Embedding Geometry and Ambiguity). A third documented use is for analyzing behavioral data, where it serves to "cluster co-occurring follow-up types into prototypical collaboration behaviors" (Prototypical Human-AI Collaboration Behaviors from LLM-Assisted Writing in the Wild). In all these cases, PCA is operationalized as an analytical tool to make high-dimensional data—whether from model internals, embeddings, or interaction logs—more interpretable by revealing underlying patterns.
