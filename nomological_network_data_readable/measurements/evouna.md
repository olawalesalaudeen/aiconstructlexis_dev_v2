# EVOUNA
**Type:** Measurement  
**Referenced in:** 3 papers  

## State of the Field

**What it is.** Papers most commonly describe EVOUNA as a question answering benchmark, though some also refer to it as a dataset. The prevailing description is that it augments QA datasets with LLM-generated responses and uses human annotations of whether each response is semantically equivalent to the golden answer; one paper further describes it as including human evaluations of five reader models across two QA datasets and as a source for constructing EMBERQA.

**What it is claimed to measure.** Across the papers, EVOUNA is linked to one behavioral indicator and no constructs. Papers use it to measure question answering, so the reported use converges on that single behavioral indicator rather than spreading across multiple constructs or indicators.

**Space of uses.** Papers position EVOUNA as an evaluation source for QA tasks. One paper uses it alongside EQAE as one of two sources for question answering data, and another uses it as source data when constructing EMBERQA; no measurement instrument is linked to it.
