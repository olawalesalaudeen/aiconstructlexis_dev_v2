# Pick-a-Pic
**Type:** Measurement  
**Referenced in:** 3 papers  

## State of the Field

**What it is.** Across the surveyed work, Pick-a-Pic is described as a large-scale open dataset derived from a web platform that collects real users' creative intentions. The prevailing description presents it as being used to evaluate whether generation aligns with user preference, and the available snippet in TIGeR: Unifying Text-to-Image Generation and Retrieval with Large Multimodal Models repeats this framing by calling it "a large-scale open dataset" that "stems from a web platform collecting real users’ creative intention."

**What it is claimed to measure.** Papers link Pick-a-Pic to one construct and no behavioral indicators. The recorded construct is Multimodal alignment: one paper treats Pick-a-Pic as measuring it by listing Pick-a-Pic among text-to-image evaluation benchmarks when reporting results on multimodal alignment.

**Space of uses.** The available usage evidence positions Pick-a-Pic as a benchmark used alongside other text-to-image evaluation benchmarks rather than in isolation. In Natural Language Inference Improves Compositionality in Vision-Language Models, it is reported together with DrawBench, EditBench, COCO-T2I, and TIFA160 when the paper says it reports results on five text-to-image evaluation benchmarks.
