# WikiHow
**Type:** Measurement  
**Referenced in:** 5 papers  
**Also known as:** Wikihow  

## State of the Field

**What it is.** Papers most commonly treat WikiHow as source data built from instructional content. Definitions describe it as a dataset of instructional articles, as a multimodal dataset, and in one study as a dataset derived from the WikiHow online knowledge base and modified by grouping related paragraphs into documents and using summaries as subheadings. Across these uses, it appears as the basis for script generation, project-based learning, and procedural step selection from text and images.

**What it is claimed to measure.** Papers link WikiHow to 1 behavioral indicator, How-to question answering, and to no constructs. The recorded claim is focused rather than spread across many outcomes: a paper reports that this dataset is used to evaluate THREAD on linear how-to questions, so WikiHow is used to measure How-to question answering.

**Space of uses.** No other measurement instrument is linked to WikiHow. Instead, papers use it as source material within broader evaluations: as the basis for a script generation task in InterleavedBench, as extracted data for MMIE's project-based learning category, as a modified dataset for evaluating organizing skill on expository text, and as a dataset for linear how-to question evaluation.
