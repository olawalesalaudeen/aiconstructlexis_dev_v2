# MUSE-Books
**Type:** Measurement  
**Referenced in:** 3 papers  
**Also known as:** BOOKS  

## State of the Field

**What it is.** The only available paper treats MUSE-Books, under the name BOOKS, as a dataset within the MUSE benchmark. In Catastrophic Failure of LLM Unlearning via Quantization, it is described as featuring the Harry Potter series, with the original novels as the forget set and related FanWiki materials as the retain set.

**What it is claimed to measure.** The available paper does not explicitly report that MUSE-Books measures any construct or behavioral indicator, and papers do not link it to any constructs or indicators.

**Space of uses.** Papers position it as a component of the MUSE benchmark rather than as a standalone protocol. The described use pairs the original Harry Potter novels as the forget set with related FanWiki materials as the retain set, with the retain set used to preserve domain knowledge post-unlearning, and no other measurement instrument is linked to it.
