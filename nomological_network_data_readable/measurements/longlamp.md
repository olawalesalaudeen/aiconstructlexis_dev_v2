# LongLaMP
**Type:** Measurement  
**Referenced in:** 3 papers  

## State of the Field

**What it is.** Papers most commonly treat LongLaMP as a benchmark dataset for long-form personalized text generation. The prevailing description is that it covers tasks such as abstract generation, topic writing, and review generation; another description presents it as an extended version of LaMP with longer-form, open-ended, and more subjective personalized generation tasks, including abstract and topic writing.

**What it is claimed to measure.** In these papers, LongLaMP is not linked to named constructs or behavioral indicators. Instead, papers describe it at the task level as evaluating long-form personalized text generation, with one description further characterizing its tasks as involving more subjective or user-specific expression.

**Space of uses.** Papers commonly use LongLaMP alongside LaMP, positioning the pair as resources for long-form and short-form personalized text generation, respectively. One study also places it within a set of open-ended personalized text generation tasks drawn from LaMP and LongLaMP.
