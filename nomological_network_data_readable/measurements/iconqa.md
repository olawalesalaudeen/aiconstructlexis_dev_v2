# IconQA
**Type:** Measurement  
**Referenced in:** 4 papers  

## State of the Field

**What it is.** Papers most commonly treat IconQA as a visual question answering dataset for diagram understanding. One definition also describes it as "a new benchmark for abstract diagram understanding and visual language reasoning," and another places it as one task within the CMIT benchmark.

**What it is claimed to measure.** Papers link IconQA to 1 behavioral indicator and no constructs. The reported measurement claim is consistent: IconQA measures visual question answering, with the task described as diagram understanding VQA, rather than being used for a wider spread of constructs or behaviors.

**Space of uses.** Within the reported uses, papers position IconQA as a visual question answering task for model comparison, including comparisons that pair it with ScienceQA and multi-task settings that include both ScienceQA and IconQA. No other measurement instrument is linked to it, and one definition frames it as a task used inside the CMIT benchmark.
