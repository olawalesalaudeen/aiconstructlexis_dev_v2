# WangchanThaiInstruct
**Type:** Measurement  
**Referenced in:** 1 paper  

## State of the Field

A human-authored Thai instruction-following dataset containing 6,916 test samples across four domains (Medical, Law, Finance, Retail) and seven task types, used for zero-shot evaluation and instruction tuning.
