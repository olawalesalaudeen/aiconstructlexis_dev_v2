## State of the Field

**What it is.** Across the available definitions, papers treat TableBench as a challenging benchmark for table reasoning. It is described as covering diverse question types and topics, with the aim of evaluating table reasoning across a wide range of scenarios.

**What it is claimed to measure.** Its reported measurement role is concentrated rather than spread across many targets: papers link it to one construct, Table reasoning, and one behavioral indicator, Table question answering. One paper places it among "widely used table reasoning datasets," while another includes it in benchmark data for evaluating table question answering.

**Space of uses.** In use, papers position TableBench as an evaluation dataset within a broader benchmark suite. One study reports experiments on WikiTableQuestions, HiTab, and TableBench, showing that it is used alongside those two benchmarks in a broader evaluation setup, and another lists it in table task and benchmark data for evaluation.
