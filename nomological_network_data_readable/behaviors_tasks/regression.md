## State of the Field

**Space of definitions.** Most definitions describe it as predicting a continuous numerical value for a given tabular record or input sample. One paper also formulates it as predicting an integer-valued output, with a user review as input and a rating from 1 to 5 as the label.

**Variants.** Papers study regression both as tabular prediction across various domains and as a review-to-rating task. The formulations differ in whether the input is a tabular record or a user review, and in whether the target is described as a continuous value or as an integer rating.
