# Function composition
**Type:** Behavior  
**Referenced in:** 3 papers  
**Also known as:** Function composition solving  

## State of the Field

**Space of definitions.** Across the papers, it is described as solving tasks that require sequentially applying functions or relations to an input and producing the resulting output. One formulation says models "apply them sequentially to a given input" and, when prompted with the non-highlighted part, need to return the highlighted part; another frames success as answering a query for "the value of f(g(x))" after composing relations such as "birthday-of" and "father-of".

**Variants.** Variation appears mainly in how the task is posed. Some papers study composed mappings built from simple functions with specified inputs and outputs, while others study relation-composition queries in which one named relation is applied and then another; the labels used are "Function composition" and "Function composition solving".

**Space of elicitation and scores.** No measurement instrument is linked to this behavior. In the available papers, it is elicited directly through the task setup itself, either by giving part of a composed mapping and asking for the missing output or by asking for the result of a composed query.

**What it is taken as evidence of.** No construct is linked to this behavior. The available papers therefore do not state what broader construct it is taken to indicate.
