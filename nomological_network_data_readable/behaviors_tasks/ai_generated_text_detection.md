# AI-generated text detection
**Type:** Behavior  
**Referenced in:** 23 papers  
**Also known as:** LLM-generated text detection, Machine-generated text detection, LLM text identification, Machine text detection, LLM text detection, AI-text detection  

## State of the Field

**Space of definitions.** Across papers, the prevailing usage is a binary authorship decision over text: deciding whether a candidate text is human-written or machine-generated, often stated more specifically as human versus LLM-generated. Definitions repeatedly frame success as distinguishing between these two sources from the observed text, sometimes for a generic text and sometimes for a given piece such as a paper submission, review, or evidence item. A smaller line of work extends the behavior from whole-text labeling to identifying which segments or sentences in a mixed-origin article were generated by an LLM.

**Variants.** Most work treats the task at whole-text or document level, and one paper notes that mainstream methods primarily target document-level long texts. Smaller variants study sentence-level detection for human-AI hybrid content and segment-level identification in partially written text, where the aim is to determine which segments were LLM-written. Papers use several near-synonymous names for the behavior, including AI-generated text detection, LLM-generated text detection, machine-generated text detection, machine text detection, and AI-text detection, and one paper relates it to authorship attribution while also mentioning boundary-detection and multi-author classification as alternative formulations.

**Space of elicitation and scores.** Operationalization is usually binary classification, with detectors predicting human-written versus machine-generated text, though one benchmark-oriented definition also allows a likelihood score or label. Papers link the behavior to three measurement instruments, HC3, M4, and TruthfulQA. In the recorded uses, HC3 and TruthfulQA provide texts for testing detection, including unseen texts and unseen human-written distributions, while M4 is described as a publicly available machine-generated text detection dataset whose Urdu subset was augmented.

**What it is taken as evidence of.** Papers do not link this behavior to any construct, so they do not specify what construct it is evidence of. The only other recorded link is a related link to authorship attribution, described in one paper as one of several task formulations.
