# Symbolic manipulation
**Type:** Behavior  
**Referenced in:** 5 papers  
**Also known as:** Symbol manipulation  

## State of the Field

**Space of definitions.** Across definitions, the prevailing usage treats symbolic manipulation as rule-based operations over symbolic inputs, especially mathematical or logical symbols. Papers describe it as the observable act of manipulating symbols according to a set of rules, and as performing operations such as identifying syntactic roles or evaluating logical conditions over structured values.

**Variants.** The behavior appears both as a broad task category and as named task instances. Papers mention tasks requiring symbolic manipulation in general, and one paper instantiates the category with Indirect Object Identification (IOI) and PriceTag within a broader set of language modeling tasks.

**Space of elicitation and scores.** No measurement instrument is linked to it. The evidence names task examples, but does not specify a separate elicitation or scoring instrument for this behavior.

**What it is taken as evidence of.** No construct is linked to it. The papers represented here do not state what symbolic manipulation is taken to indicate.
