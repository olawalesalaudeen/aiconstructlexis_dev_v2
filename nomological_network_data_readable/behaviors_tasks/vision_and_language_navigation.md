# Vision-and-language navigation
**Type:** Behavior  
**Referenced in:** 3 papers  
**Also known as:** Vision-language navigation  

## State of the Field

**Space of definitions.** Across the definitions, the framing is consistent: an embodied agent follows natural language instructions to navigate through a visual environment, with success described as reaching a target destination or completing the language-specified goal. One paper also phrases the task as grounding a destination point within a given environment, which matches the same instruction-following navigation setup.

**Variants.** The named settings are high-level vision-language navigation tasks in ALFRED and a broader range of environments described as both discrete action and continuous robotic control. Papers also use closely aligned names such as vision-language navigation and VLN for the same instruction-guided navigation behavior.

**Space of elicitation and scores.** No measurement instrument is linked to it in these papers, so they do not identify a recurring instrument for eliciting or scoring this behavior.

**What it is taken as evidence of.** No construct is linked to it as what this behavior indicates, so the papers do not specify a construct that it is taken to reflect.
