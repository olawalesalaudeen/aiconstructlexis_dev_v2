# Adversarial attacks
**Type:** Behavior  
**Referenced in:** 7 papers  
**Also known as:** Adversarial attack response, Trigger generation, Adversarial example generation, SQL injection  

## State of the Field

**Space of definitions.** Across the surveyed work, the prevailing usage treats adversarial attacks as generating modified or perturbed inputs that make a target model fail: papers describe models asked to "output adversarial examples that attack the defense," including image perturbations under a perturbation bound and text changes that are either lexically similar but semantically different, or semantically similar to the original, while causing incorrect predictions or misclassification. A smaller line of work uses the same label for responses to jailbreak or adversarial probes that induce forgotten knowledge, for hidden trigger generation that can activate a backdoor in an evaluator, and for malicious SQL payload injection that manipulates queries or extracts database data. Success is therefore framed differently across papers, including fooling a model, eliciting forgotten knowledge, activating a backdoor, or achieving outcomes such as successful login or database dumping.

**Variants.** Variants span image, text, model-evaluation, and web-application settings. The most common named variant is adversarial example generation, covering bounded image attacks, NLI sentence-pair modification with antonym replacements, and adversarial text generation with sensitivity-guided perturbation prompts. Other variants are adversarial attack response for unlearning evaluation, trigger generation for backdoored evaluators, and SQL injection through application inputs.

**Space of elicitation and scores.** No measurement instrument is linked to this behavior.

**What it is taken as evidence of.** The only linked construct is Robustness. In the recorded relationship, a paper treats Robustness as measured by adversarial attacks, describing robustness as the ability to deliver a correct result even when input is manipulated by malicious actors and assessing it by seeking adversarial examples. No other construct linkage is recorded.
