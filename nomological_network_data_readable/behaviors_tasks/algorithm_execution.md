# Algorithm execution
**Type:** Behavior  
**Referenced in:** 3 papers  
**Also known as:** Multi-step execution  

## State of the Field

**Space of definitions.** Across the surveyed work, the prevailing framing treats this behavior as carrying out a sequence of steps or operations to solve a problem. Definitions converge on observable execution itself, with one line describing a sequence of computational steps defined by an algorithm and another using the broader formulation of multi-step execution; one paper further associates it with "enumeration, precise computation, and algorithm execution through tool interaction" (START: Self-taught Reasoner with Tools).

**Variants.** Papers use both the names algorithm execution and multi-step execution. A narrower variant places it in tool-based settings, often via a code interpreter and tool interaction, while a broader variant studies it within advanced reasoning tasks; KOR-Bench: Benchmarking Language Models on Knowledge-Orthogonal Reasoning Tasks also notes that, in Cipher reasoning, errors are frequent in multi-step execution alongside position mapping, transpose writing, mathematical calculation, and split connection.

**Space of elicitation and scores.** No measurement instrument is linked to it.

**What it is taken as evidence of.** No construct is linked to it.
