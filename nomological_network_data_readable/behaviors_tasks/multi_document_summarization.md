# Multi-document summarization
**Type:** Behavior  
**Referenced in:** 5 papers  
**Also known as:** Document merging  

## State of the Field

**Space of definitions.** Across the definitions, the prevailing usage treats this as producing a coherent or concise summary from multiple input documents that synthesizes salient or key information into one output. Some authors explicitly allow either general or query-focused summaries, while one paper instead uses the name document merging for combining multiple document inputs into a single coherent, non-redundant output.

**Variants.** Variants mainly differ by task scope and source setting: papers distinguish general multi-document summarization from query-focused multi-document summarization, and one line uses the alternate label document merging. The source documents are sometimes described as materials about a single topic or entity, with examples such as news articles about an event or reviews of a product.

**Space of elicitation and scores.** Papers do not link this behavior to a named measurement instrument. The only operational detail reported alongside the task is that one study used "the dataset and the evaluation prompt provided by GoT for document merging."

**What it is taken as evidence of.** No construct is linked to it.
