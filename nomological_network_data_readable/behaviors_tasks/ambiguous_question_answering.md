# Ambiguous question answering
**Type:** Behavior  
**Referenced in:** 3 papers  

## State of the Field

**Space of definitions.** The available definition treats it as generating one or more valid answers to a query that is inherently ambiguous and allows multiple interpretations. In the same usage, the task is framed as tackling ambiguity, and a conditional form is described as doing so by incorporating explicit conditions.

**Variants.** The named variant in the papers is Conditional Ambiguous Question-Answering (CondAmbigQA), presented as a framework that incorporates explicit conditions. Alongside that label, the broader task is also referred to as ambiguous QA.

**Space of elicitation and scores.** Papers link this behavior to one measurement instrument, ASQA. One paper describes ASQA as an ambiguous QA dataset, so the operationalization shown here is dataset-based.
