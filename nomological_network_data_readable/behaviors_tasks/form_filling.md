# Form filling
**Type:** Behavior  
**Referenced in:** 3 papers  

## State of the Field

**Space of definitions.** Across the available definitions, the prevailing usage is entering or selecting values in web form elements according to task instructions. The behavior is described both as entering information into fields and as interacting with inputs such as text boxes, checkboxes, radio buttons, and dropdown menus. One definition also includes tracking which fields have been completed, and one paper describes repeated input of the same words into the same field as a common error in this behavior.

**Variants.** The papers describe this behavior across several web input types rather than as a single uniform action. Related formulations include labeling or filling in inputs, and the named action types include "modify_text", "modify_checkbox", "modify_radio", and "modify_select".

**Space of elicitation and scores.** No measurement instrument is linked to it. In the available descriptions, the behavior is operationalized through web interaction actions such as filling or labeling inputs and modifying text, checkbox, radio, and select elements.

**What it is taken as evidence of.** No construct is linked to it as evidence of.
