# Low-light image enhancement
**Type:** Behavior  
**Referenced in:** 3 papers  
**Also known as:** Low-light enhancement  

## State of the Field

**Space of definitions.** Across the definitions, the prevailing usage treats it as improving the brightness and visibility of images taken under low-light conditions. Some authors additionally make it instruction-guided, with a textual instruction specifying the edit, while another description also includes reducing noise and improving image quality. One study describes successful outputs as "clearer and more natural" while "reducing noise and enhancing visibility" (PromptFix: You Prompt and We Fix the Photo).

**Variants.** Papers use both the names "low-light enhancement" and "low-light image enhancement." The main variation is by setting: some work treats it as an instruction-based image editing task, while other papers place it within image restoration, and one paper relates Image restoration to Low-light image enhancement by describing it among blind restoration tasks.

**Space of elicitation and scores.** The papers describe the task directly, but no measurement instrument is linked to it. No instrument is named as eliciting or scoring this behavior.

**What it is taken as evidence of.** No construct is linked to it as evidence of a broader construct. Instead, the only linked relation outside the task descriptions is that Image restoration is related to Low-light image enhancement in one paper.
