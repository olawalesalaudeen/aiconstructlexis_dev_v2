# Claim detection
**Type:** Behavior  
**Referenced in:** 4 papers  

## State of the Field

**Space of definitions.** Across the available work, the prevailing framing treats claim detection as deciding, at the sentence level, whether a transcript sentence contains a claim that should be labeled for fact-checking or related categories. The same usage also describes it as a first step, with success defined by identifying which sentences contain claims under a claim taxonomy.

**Variants.** In the available usage, claim detection is studied on video transcripts, specifically transcripts of YouTube Short videos. The task is set up as multilingual and multilabel, with sentence-level annotation using a claim taxonomy.

**Space of elicitation and scores.** No measurement instrument is linked to this behavior. The available description instead operationalizes it through sentence-level annotation of transcript sentences with a claim taxonomy.

**What it is taken as evidence of.** Papers do not directly present this behavior as measuring a construct here. The only linked construct is Verifiability, and it is described only as related: one paper says that assessing verifiability begins by determining whether a comment includes any claims.
