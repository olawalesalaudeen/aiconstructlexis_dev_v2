# Tweet generation
**Type:** Behavior  
**Referenced in:** 3 papers  

## State of the Field

**Space of definitions.** Across the papers, the prevailing usage treats tweet generation as producing short-form text in tweet format in response to an instruction or prompt. The common formulation is that the model returns the tweet itself, with one paper stating that in this task the response is "the exact tweet"; another frames it through prompts tailored to "a specific medium (a tweet)" and through creating instructions for a tweet.

**Variants.** A recurring variant is community-specific tweet generation, where papers describe generating tweet-like text on given topics for a specified community, including creating a synthetic corpus by prompting a community-aligned model to generate tweets. Another formulation has an attacker LLM create instructions for a tweet, with the prompt design adapted to the tweet medium.

**Space of elicitation and scores.** No measurement instrument is linked to tweet generation.

**What it is taken as evidence of.** No construct is linked to tweet generation.
