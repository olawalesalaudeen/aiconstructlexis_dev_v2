# Input regurgitation
**Type:** Behavior  
**Referenced in:** 4 papers  
**Also known as:** Verbatim text extraction, Context parroting  

## State of the Field

**Space of definitions.** Across definitions, the prevailing usage treats this behavior as output that reproduces provided context verbatim or near-verbatim. Most descriptions focus on copied augmented input or retrieved datastore text, and one privacy-oriented definition explicitly presents such reproduction as potentially indicating privacy leakage, saying that "the model regurgitates them." Another formulation broadens it to "context parroting," where a forecast repeats or closely mimics subsequences from the input context, while a narrower cross-modal usage treats it as a failure mode where the model repeats or describes the prompt instead of following the intended task.

**Variants.** Papers use several labels for closely similar output patterns: input regurgitation, verbatim text extraction, and context parroting. The behavior is studied with augmented input context, retrieved datastore text, cross-modal few-shot prompts, and forecasting settings; in the cross-modal case, one paper says the model "captions" or "regurgitates" the input rather than adhering to the demonstrated pattern.

**Space of elicitation and scores.** No measurement instrument is linked to it. Instead, papers operationalize it directly through the model output: reproducing verbatim or near-verbatim portions of augmented context, producing retrieved text nearly unchanged, repeating or closely mimicking input subsequences, or repeating or describing the prompt rather than performing the intended task.

**What it is taken as evidence of.** Only one construct is linked in the papers, In-context learning. One paper reports a related link from In-context learning to Input regurgitation, attributing model success to in-context learning and identifying context parroting as "a simple mechanism" used by these models to capture long-term behavior.
