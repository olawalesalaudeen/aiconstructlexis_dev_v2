# Keyword generation
**Type:** Behavior  
**Referenced in:** 3 papers  
**Also known as:** Ad keyword generation  

## State of the Field

**Space of definitions.** The prevailing usage is to treat keyword generation as producing a list of words or short phrases from an input. Papers agree on the list-generation format and on outputs being salient or relevant keywords, but they differ on the target: some ask for descriptors of a depicted person, including characteristics or personality traits, while others ask for terms that represent a document’s core concepts, in some cases including terms not present in the document itself (tRAG: Term-level Retrieval-Augmented Generation for Domain-Adaptive Retrieval), or for product-related keywords for sponsored search advertising.

**Variants.** Papers use the label for several settings. One line prompts for keywords about a depicted person’s characteristics or personality traits (Uncovering Bias in Large Vision-Language Models at Scale with Counterfactuals); another treats it as domain-specific document keyword generation, where few-shot demonstrations guide generation of a keyword list for each document in a corpus; advertising-focused work also uses the name Ad keyword generation for generating product keywords and describes the process as fully automated with minimal human supervision.

**Space of elicitation and scores.** No measurement instrument is linked to this behavior in the papers, so the available descriptions stay at the level of task prompts and generation procedures.

**What it is taken as evidence of.** No construct is linked to this behavior in the papers, so they do not explicitly treat it as evidence of any construct.
