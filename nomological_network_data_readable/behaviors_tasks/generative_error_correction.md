# Generative error correction
**Type:** Behavior  
**Referenced in:** 3 papers  
**Also known as:** Hypotheses-to-transcription mapping  

## State of the Field

**Space of definitions.** Across the cited papers, the prevailing usage treats generative error correction as an ASR task where an LLM maps an N-best list of hypotheses to a corrected transcription. The papers align on the input, ASR N-best hypotheses, and the target, a final or ground-truth transcription; one definition further specifies that this is done in an auto-regressive manner, and one snippet describes it as "a direct mapping from the N-best hypotheses list generated by an ASR system to the predicted output transcription" (It's Never Too Late: Fusing Acoustic Information into Large Language Models for Automatic Speech Recognition).

**Variants.** The formulations that appear are all within automatic speech recognition settings. A recurring name for the core setup is a hypotheses-to-transcription, H2T, mapping from an N-best hypotheses list to a predicted or ground-truth transcription, alongside the shorthand GER.

**Space of elicitation and scores.** Papers link it to 1 measurement instrument, HyPoradise. In the recorded relationship language, generative error correction is measured by HyPoradise, which is described as a generative error correction benchmark for LLM-enhanced ASR and as a dataset of hypotheses-transcription pairs used to learn the mapping from ASR N-best hypotheses to ground-truth transcription.

**What it is taken as evidence of.** No construct is linked to it, so the papers do not explicitly treat this behavior as evidence of a named construct.
