# Pattern inference
**Type:** Behavior  
**Referenced in:** 3 papers  
**Also known as:** Pattern completion  

## State of the Field

**Space of definitions.** Across the available definitions, the prevailing usage treats pattern inference as a visual rule-discovery task: a model must identify and generalize a pattern and then use that rule to complete a missing element. Papers largely agree on this core formulation, but differ in the visual setup, with one describing completion of a matrix of abstract shapes and another describing a sequence of frames in which the correct element must satisfy an underlying rule. Success is framed as correctly completing the pattern or selecting the element that completes the sequence.

**Variants.** Authors use both pattern inference and pattern completion for this behavior. One paper places it within a multimodal reasoning taxonomy and describes it as a math problem centered on abstract shape matrices, while another studies it through Raven's Progressive Matrices, where object attributes evolve according to different rules across frames and the task is to complete the sequence.

**Space of elicitation and scores.** No measurement instrument is linked to it in the papers.

**What it is taken as evidence of.** No construct is linked to it in the papers, so there is no recorded agreement or disagreement about what broader construct it reflects.
