# Action execution
**Type:** Behavior  
**Referenced in:** 4 papers  

## State of the Field

**Space of definitions.** One paper treats action execution as the agent's observable performance of a specific action from its available action space within an environment. The same paper describes an interaction module that executes actions in the environment according to the task and records the process, so the behavior is framed as observable, task-conditioned action taking.

**Space of elicitation and scores.** Papers link action execution to 1 measurement instrument, T-Eval, which is the only linked instrument. One paper places T-Eval under the Action Execution category of agentic tasks, so the linked measurement usage centers on that single instrument.

**What it is taken as evidence of.** Papers relate action execution to 2 constructs, Planning and Reasoning. These links are stated as related rather than causal, correlational, or measurement claims, so the construct-level framing shown here is connection to those two constructs rather than a direct claim that action execution measures one agreed construct.
