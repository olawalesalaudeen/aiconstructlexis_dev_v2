# Outline generation
**Type:** Behavior  
**Referenced in:** 4 papers  

## State of the Field

**Space of definitions.** The available definition treats outline generation as a preparatory writing step: creating a structured plan or hierarchy of sections for an article before drafting the full content. In "OmniThink: Expanding Knowledge Boundaries in Machine Writing through Thinking", it is formulated as generating an outline from retrieved information and an input topic, as in the quoted procedure, "Generate an outline O = Generate(I, T) based on the retrieved information I and input topic T."

**Variants.** The described setting is article writing, where the outline is built from retrieved information and a topic. A related use appears in a presentation workflow: one paper relates outline generation to slide generation and states that slides are produced "Guided by the presentation outline from the previous phase," which places outline generation in a presentation setting as well.

**What it is taken as evidence of.** No construct is linked to it as something this behavior indicates.
