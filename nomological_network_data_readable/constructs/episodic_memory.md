# Episodic memory
**Type:** Construct  
**Referenced in:** 7 papers  

## State of the Field

**Definition agreement:** Complementary. All papers define episodic memory as recalling specific past episodes or interactions rather than general knowledge, but they frame that phenomenon at different levels. One paper gives a broad model-level definition in terms of storing and retrieving sequence-specific information, while the others emphasize autobiographical, time-and-place grounded events or past user interactions, so the definitions differ in scope and setting but can be combined without contradiction.

**Space of definitions.** Across the papers, the prevailing usage centers on recall of specific past events or information rather than general knowledge. Most definitions describe episodic memory as storing and retrieving specific sequence-level or event-level content, often explicitly separated from generalized world knowledge or semantic memory. Some authors make this more specifically autobiographical, defining it through personally experienced events grounded in time and place, past conversations, or historical user engagements. The main variation is between a sequence-storage framing and a personal-event framing, while both preserve specificity and contrast with more general knowledge.

**Space of facets.** Papers most often systematize episodic memory by contrasting it with semantic or generalized knowledge: one description says it stores sequence-specific information independent of the natural language knowledge a model has, while another contrasts it with semantic memory that stores general knowledge. Some authors also equate it with autobiographical memory or specific personal experiences, including recall of a specific conversation, so the same label is used both for model state that carries prior sequence information and for memory of prior user events. Recurring facets are specificity to individual events, ties to time and space, and reuse of prior interactions.

**Space of measurement.** No measurement instrument is linked to episodic memory, and no behavioral indicator is linked to it. The papers therefore do not share a recorded benchmark, human evaluation procedure, LLM-as-a-judge method, probe, or analysis for measuring it. One paper instead describes embeddings or recurrent state as serving as an episodic memory that stores sequence-specific information, but this is not linked as a recorded measurement instrument.
