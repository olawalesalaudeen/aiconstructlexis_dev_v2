# Abstract visual reasoning
**Type:** Construct  
**Referenced in:** 3 papers  

## State of the Field

**Definition agreement:** Too little evidence.

**Space of definitions.** Across the surveyed work, the concept is framed as an ability: identifying high-level, abstract patterns that govern relationships among visual shapes and their attributes within a specific task configuration. In MARVEL: Multidimensional Abstraction and Reasoning through Visual Evaluation and Learning, this is illustrated with AVR problems that require finding patterns such as repetition constraints on numbers that control input shapes in a matrix, and no competing definition appears.

**Space of measurement.** Papers do not link this construct to any measurement instrument or behavioral indicator. The only concrete operational description is task-based: AVR problems are described as requiring the solver to detect high-level patterns that control the input shapes in a specific configuration, for example repetition constraints in a matrix.

**Links.** One paper claims a causal relationship from visual perception to abstract visual reasoning. In MARVEL: Multidimensional Abstraction and Reasoning through Visual Evaluation and Learning, the evidence is that "a single error in visual feature perception can impact reasoning since the correct pattern must apply to all puzzle shapes," treating visual perception as affecting abstract visual reasoning.
