# Working memory
**Type:** Construct  
**Referenced in:** 4 papers  

## State of the Field

**Definition agreement:** Complementary. Most papers define working memory as a capacity to actively hold and manipulate information across a context or interaction so it can guide task performance. One paper instead emphasizes holding and integrating many task-relevant features during decision making, which is a narrower, compatible aspect of the same capacity rather than a different construct.

**Space of definitions.** Across the papers, the prevailing usage treats working memory as the capacity to hold and manipulate task-relevant information while performing a task. Most definitions share that core, but they anchor it differently: some frame it as an LLM analogy tied to the context window and to representation learning, some describe it over the course of an interaction so that information can guide current and future actions, and another describes it as holding and integrating many features at once for a decision. The variation is mainly in whether the capacity is attached to context windows, interaction, or decision aggregation.

**Space of facets.** Papers do not break working memory into formal subtypes. Instead, they place it in different local systems: it is connected to representation learning and the context window in one line of work, grouped with other cognitive abilities for verbal interaction such as common-sense reasoning and theory of mind in another, and glossed more narrowly as aggregating features for a decision in another. The same label is thus used both as a broad cognitive ability and as a more specific decision-focused operation.

**Space of measurement.** No measurement instrument or behavioral indicator is linked to working memory. The papers invoke it in relation to context windows, dialogue games, and decisions involving many features, but no direct measure is linked to it.
