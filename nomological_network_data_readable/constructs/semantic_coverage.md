# Semantic coverage
**Type:** Construct  
**Referenced in:** 3 papers  

## State of the Field

**Definition agreement:** Too little evidence.

**Space of definitions.** In the available work, semantic coverage is treated as a property of model-generated text relative to a reference text: the degree to which the generated text captures the topics, concepts, and meaning present in that reference. The same paper also uses it as one of the aspects for evaluating LLM-generated context against human-written counterparts, alongside factual consistency.

**Space of measurement.** No measurement instrument or behavioral indicator is linked to it. In the available paper, it is operationalized by calculating semantic coverage between LLM-generated context and human-written context using commonly employed semantic similarity metrics and Key Point Recall (KPR), a metric-based analysis that follows the definition's focus on coverage of topics, concepts, and meaning.
