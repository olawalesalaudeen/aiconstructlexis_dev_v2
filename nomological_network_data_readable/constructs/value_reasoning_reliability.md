# Value-reasoning reliability
**Type:** Construct  
**Referenced in:** 3 papers  
**Also known as:** Value consistency  

## State of the Field

**Definition agreement:** Too little evidence.

**Space of definitions.** Across the available definitions, papers do not converge on a single framing. One paper uses a broad reliability definition: stable, consistent value-based judgments across repeated prompts, perturbations, persuasion, and open-ended expression tasks. Another paper uses the label value consistency for a narrower idea, maintaining adherence to a target value under opposing or conflicting guidance, including opposite or potentially malicious prompts. The clearest difference is scope: multi-condition stability of value reasoning versus resistance to prompt-level conflict around a target value.

**Space of facets.** The broader framing is explicitly decomposed into output consistency under identical prompts, output robustness under semantically equivalent prompts, maintaining stable value reasoning in the face of attacks, and consistency in open-ended value expression tasks. Terminology is not uniform, because one paper names the construct Value-reasoning reliability while another uses value consistency for adherence to a target value under conflicting guidance. The sole linked construct is Consistency, which one paper treats as related to Value-reasoning reliability.

**Space of measurement.** It is linked to no measurement instrument and no behavioral indicator. Still, the papers operationalize it through prompt-based evaluations: repeated identical prompts, semantically equivalent prompt perturbations, attacks or persuasion, open-ended value expression, and tests with opposite or potentially malicious prompts. These operationalizations track the definitions closely, focusing either on stable value judgments across prompt conditions or on retaining a target value under opposing guidance.

**Links.** One paper reports that Consistency is related to Value-reasoning reliability, using language that includes output consistency under identical prompts as part of the construct. No causal or correlational links are reported.
