**Type:** Construct  
**Referenced in:** 2 papers  
**Also known as:** Action execution, Action-level ability  

## Sources

**[Can Compressed LLMs Truly Act? An Empirical Evaluation of Agentic Capabilities in LLM Compression](https://raw.githubusercontent.com/mlresearch/v267/main/assets/dong25k/dong25k.pdf) (as "Action execution")**

**[A Mathematical Framework for AI-Human Integration in Work](https://raw.githubusercontent.com/mlresearch/v267/main/assets/celis25a/celis25a.pdf) (as "Action-level ability")**
