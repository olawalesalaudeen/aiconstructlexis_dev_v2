# Irrelevance detection ability
**Type:** Construct  
**Referenced in:** 3 papers  
**Also known as:** Irrelevance detection  

## State of the Field

**Definition agreement:** Too little evidence.

**Space of definitions.** The available paper frames this construct as a model-side ability to recognize when none of the available functions or tools matches the user's intent and to refuse the task in that case. In that usage, irrelevance detection centers on judging that "no suitable function exists" and "decline the task, rather than making incorrect attempts" (Robust Function-Calling for On-Device Language Model via Function Masking).

**Space of measurement.** No measurement instrument or behavioral indicator is linked to it. In the available use, the construct is stated as a capability, but it is not tied to a named benchmark, human evaluation method, judge model, probe, or analysis.

**Links.** One paper reports that it is correlated with Tool use ability, describing an inverse relationship between accurate function-call execution and irrelevance detection capacity.
