# Short-context ability
**Type:** Construct  
**Referenced in:** 3 papers  
**Also known as:** Short-context capabilities, Short-context proficiency, Short-context capability  

## State of the Field

The latent ability of a model to perform well on tasks where the required information is contained within a short input context.

## Sources

**[LongPO: Long Context Self-Evolution of Large Language Models through Short-to-Long Preference Optimization](https://proceedings.iclr.cc/paper_files/paper/2025/file/1332893b662f655660c9abdf793230cf-Paper-Conference.pdf) (as "Short-context proficiency")**

> The set of core abilities demonstrated on tasks with short input contexts, such as general knowledge and reasoning, which should be preserved after modification.
