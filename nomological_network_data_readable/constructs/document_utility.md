# Document utility
**Type:** Construct  
**Referenced in:** 3 papers  
**Also known as:** Retrieval utility  

## State of the Field

The latent property of a document indicating its usefulness for generating correct answers in a retrieval-augmented generation context, distinct from topical relevance.
